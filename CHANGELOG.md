# Changelog

All notable changes to this project will be documented in this file. Releases from 1.0.0 onward are generated automatically by [semantic-release](https://semantic-release.gitbook.io/) from Conventional Commits; see [RELEASING.md](RELEASING.md).

## [0.1.0] - 2025-02-19

### Added

- Convert images to JPEG, PNG, WebP, GIF, AVIF, TIFF, HEIF, JP2 from Explorer context menu
- Edit images: rotate 90° CW/CCW, flip, flop, trim, greyscale, negate
- Configuration for conversion quality and save-as behavior (leave original vs replace)
